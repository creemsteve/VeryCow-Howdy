# VCH 0.1.3

This release adds ordered server roles, role assignment, channel permission overrides and delegated management of lower roles. Server-side checks protect channel visibility, message sending, voice connections and key delivery. Changes to role access rotate channel keys for future traffic. Existing account allow lists and private friend channels remain in force.

Desktop chat now displays profile pronouns beside the sender's name. The release also includes the friends, calls, image staging, typing indicators, appearance and voice updates in this source tree.

Update the server and clients together. Android packages are debug-signed and intended for testing. Access changes cannot erase messages or keys already saved by clients. See README.md and SECURITY.md for deployment and security details.
